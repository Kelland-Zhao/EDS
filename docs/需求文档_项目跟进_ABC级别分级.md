# 需求文档 — 项目跟进 CI/Kaizen 项目 ABC 级别分级

- 版本：V20260814.01（2026-08-14 确认）
- 模块：ProjectTracking（项目跟进）
- 后端表：`项目总表`（SS_ID `1aoQDjeWU9Xa9clloyTwiXL6WS62tYVbB0-VOavpAgAM`）
- 关联文档：[需求文档_项目跟进2.0.md](./需求文档_项目跟进2.0.md)

---

## 1. 背景

CI / Kaizen 类项目需要按**重要程度分级**：A类=重大改进、B类=一般改进、C类=小改进。当前项目跟进页面无此维度，领导无法按级别查看/排序项目。

## 2. 范围

- **适用类型**：仅 `CI` / `Kaizen`。`新品/新自动化` 项目不参与分级（无徽章、不受级别筛选与排序影响）。
- **粒度**：**项目级**——整个项目一个级别，所有事项共用。
- **本期用途**：列表显示徽章、按级别筛选、列表默认排序（A→B→C→未分级在前）、为后续统计预留数据。

## 3. 数据层

`项目总表` 现有列 A~J（A 名称 / B Leader / C 技术员 / D 状态 / E Milestones_JSON / F 类型 / G 项目编号 / H 创建时间 / I 完成时间 / J 工序）。

**在 J 列后追加 K 列（index 10）**：

| 列 | index | 字段 | 取值 |
|----|-------|------|------|
| K | 10 | 级别 / Level | `A` / `B` / `C`；`新品/新自动化` 与历史项目留空 |

- 追加而非插入（G~J 列被 `PROJECT_ID_COL`/`PROJECT_CREATED_COL`/`PROJECT_COMPLETED_COL`/`PROJECT_PROCESS_COL` 等代码读写，插入会导致索引整体右移）。
- Code.js 新增常量 `PROJECT_LEVEL_COL = 10`。
- 后端规范化：仅接受 `A`/`B`/`C`（大小写归一），其他值一律存空。
- **历史数据**：现有 CI/Kaizen 项目 K 列留空 = 「未分级」，**不自动回填**（不编造数据）。

## 4. 前端改动

### 4.1 录入弹窗（addModal）
- 类型选 `CI`/`Kaizen` 时显示「级别」选择（A类 / B类 / C类），**默认 C 类**；选 `新品/新自动化` 时隐藏。
- 提交时 `level` 随项目写入 K 列；标准项目写空。

### 4.2 更新弹窗（updateModal）
- 「级别」下拉：A类 / B类 / C类 / 未分级（选「未分级」= 清空 K 列）。
- 仅 CI/Kaizen 项目显示该控件；与类型切换联动显隐。
- 级别变更写入变更记录 `changes.level` 并记入 `ProjectTracking_History`（格式与「类型变更」一致），触发更新通知邮件。
- 已完成（Done）项目沿用现有规则：仅状态可改，级别不可改。

### 4.3 主列表
- **徽章**：类型徽章旁新增级别徽章，仅 CI/Kaizen 显示：
  | 级别 | 颜色 | 文案 |
  |------|------|------|
  | A | 红 `#dc3545` | A类 |
  | B | 橙 `#fd7e14` | B类 |
  | C | 绿 `#198754` | C类 |
  | 空 | 灰 `#adb5bd` | 未分级 |
- **筛选**：筛选条新增「级别」下拉（全部 / A / B / C / 未分级）。选具体级别时：仅显示该级别的 CI/Kaizen 项目，标准项目被过滤掉；「全部」显示所有项目。
- **排序**：主列表默认排序改为：CI/Kaizen 项目按 A→B→C→未分级 排前（同级别内按项目名称），标准项目排在其后（保持原名称排序）。DataTable 隐藏排序列实现，用户仍可点击表头手动改排序。

## 5. 验收标准

1. 新建 CI 项目选「A类」→ 列表显示红色「A类」徽章，默认排序排在最前。
2. 新建 Kaizen 项目选「B类」→ 橙色「B类」徽章。
3. 新建/编辑新品/新自动化项目：无级别控件、无徽章、不受级别筛选与排序影响。
4. 级别筛选选「C」→ 仅剩 C 类 CI/Kaizen 项目。
5. 历史 CI/Kaizen 项目显示灰色「未分级」，K 列数据未被擅自写入。
6. 更新弹窗修改级别 → `项目总表` K 列更新、History 记录「级别变更」、管理员收到更新通知。
7. `getProjectTrackingData` 返回 `level` 字段，取值与 K 列一致。

## 6. 决议记录

1. **加在哪层**：K 列追加（index 10），不插列、不动 JSON。✅ 已确认
2. **粒度**：项目级（非事项级）。✅ 已确认
3. **录入默认值**：默认 C 类（多数为小改进，可改）。✅ 已确认
4. **历史回填**：不回填，留空显示「未分级」。✅ 已确认
5. **筛选语义**：选具体级别时隐藏标准项目（级别是 CI/Kaizen 专属维度）。
6. **徽章配色**：A红 / B橙 / C绿 / 未分级灰。
