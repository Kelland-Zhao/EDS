# 保养主数据管理页（A 阶段）设计文档

- 日期：2026-08-19
- 状态：设计定稿（用户已逐节确认）
- 范围：PM 模块网页可视化第一阶段 A——保养主数据 Web 管理页（第二阶段 B 为可视化看板，另立文档）

## 1. 背景与目标

保养模块已有执行类页面（PM_Plan / PM_Task / PM_Production_Confirm / PM_RecordQuery / PM_ShiftFollowUp），但**保养主数据目前仍以 Excel 草稿管理**（"CSX PM Info Summay" 电子表格的 MasterData sheet，80 行 × 15 列，代码中无任何引用）。

目标：把主数据管理做成网页版（A），替代 Excel 草稿；之后建设可视化看板（B），最终形成主数据 → 工单任务生成的完整链路（C，视需要）。A 是地基。

## 2. 数据落点

- **新建独立电子表格**专存主数据（不挂到现有 PM 工单库，权限与协作更干净）。
- 草稿表仅用于首次导入，导入后不再被系统引用。
- 为 B 阶段预留：`主数据ID` 作为看板关联键。

## 3. 数据模型

草稿 15 列原样保留（列名一致，导入按列名映射）：

| 列 | 表头 |
|---|---|
| A | 工序 |
| B | Machine Type |
| C | PM Frequency |
| D | 单次停机时间/ h |
| E | PM Description |
| F | RBM保养间隔时间 |
| G | RBM保养提醒间隔时间 |
| H | 强制保养频率/ Month |
| I | 策略 / Strategy |
| J | TasklistName |
| K | 是否创工单 |
| L | 工单类型 |

附加列：

| 列 | 表头 | 说明 |

| P | 主数据ID | 主键，格式 PM-MD-0001，自增，删除不复用 |
| Q | 确认人 | 审核通过的工号/姓名 |
| R | 确认时间 | 审核时间 |

"是否确认"列为页面状态徽章（未确认=灰 / 已确认=绿），不手工编辑 TRUE/FALSE。

### 3.2 变更日志 sheet

时间、工号、姓名、动作（新增/修改/删除/确认/取消确认/导入）、主数据ID、字段、旧值、新值。

## 4. 权限模型

- **编辑**：userID 表中所有人员（设备部）可编辑未确认行。
- **审核**：userID 表新增一列——第 1 行 `EDS`、第 2 行 `PM策略审核`、人员行 `Y/N`。
- **审核验证流程**：工号+姓名+密码（复用现有 userID 验证方式，与 PM_Task planner 验证同一数据源）且 `PM策略审核=Y`。
- 确认 / 取消确认 / 修改已确认行（解锁）均需审核验证。

## 5. 功能集（V1）

1. **增删改查 CRUD**：可编辑网格 + 新增行 / 复制选中行 / 删除选中行 / 保存（整表批量提交，后端对比旧值写变更日志）。
2. **草稿导入**：按列名从草稿 MasterData 映射到正式表；导入行为"全部新增、状态=未确认"，写一条导入日志；正式表非空时拒绝导入（提示先清空），差异比对导入留 V2。
3. **筛选搜索 + 复制 + 变更记录**：工序（多选）/策略/确认状态/机型关键字筛选；复制行快速新增；变更日志标签页可查。
4. **确认流转**：勾选行 → 确认按钮 → 工号+姓名+密码弹窗 → 后端审核校验 → 写入确认人/时间；支持取消确认。

## 6. H 列"强制保养频率/ Month"处理

- **自动换算 + 可改**：编辑 C 列频率文本时自动换算 H 列月数，H 列仍可直接手改。
- 换算表：半年=6、年=12、三年=36、双年=24、五年=60、季=3、季度=3、月=1、双月=2、周=0.25、双周=0.5、三周=0.75、五周=1.25、0.5周=0.125。
- 无法识别的频率留空并标黄提醒。
- 草稿中 16 个 `#VALUE!` 行导入后 H 列为空，待页面补填（按频率自动算出）。

## 7. 页面设计

- 新文件：`PM_MasterData.html` + `PM_MasterData-js.html`，沿用现有技术栈（Bootstrap5 + DataTables + Select2 + SweetAlert2，双语提示 swalTitle/swalHtml 风格）。
- 布局：顶部筛选栏；工具栏按钮（新增/复制/删除/导入草稿/确认/取消确认/保存/刷新）；DataTable 可编辑网格；变更日志标签页。
- 下拉列：工序、策略（TBM/RBM/CBM）、工单类型（PM02/PM10/NA/ZPM4）、是否创工单（Y/N）、是否计入AEM。
- 文本列：机型、保养描述、任务清单名、备注、RBM 间隔（F/G）、单次停机时间。
- 已确认行锁定显示，解锁需审核验证。
- Navigation.html 增加"PM 主数据"入口。

## 8. 后端函数（Code.js 新增）

| 函数 | 职责 |
